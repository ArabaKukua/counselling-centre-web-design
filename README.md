# Airdrie Counselling Centre Website Redesign

UX/UI Design Case Study

---

## Project Overview

The Airdrie Counselling Centre website redesign was created to improve usability, accessibility, and trust for individuals seeking counselling services.

My objective was to simplify navigation, improve the presentation of information, and create a welcoming digital experience that reflected the organization's mission.

## The Problem

The existing website contained a large amount of information but could be overwhelming for users looking for counselling services.

Several opportunities existed to improve navigation, readability, accessibility, and overall user experience.

---

## Goals

Improve navigation

Increase accessibility

Simplify information

Build trust

Improve mobile experience

---

## Research

I reviewed counselling websites across Alberta and identified common usability patterns.

I also considered accessibility principles and how individuals experiencing stress or crisis interact with healthcare websites.
